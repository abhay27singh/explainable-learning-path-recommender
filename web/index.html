Explainable Learning Path Recommender

Knowledge tracing and prerequisite-aware recommendation over the Open University Learning Analytics Dataset.

Demonstration system. Passwords are hashed with scrypt and never stored in plain text, and sessions use httpOnly cookies. But this runs over plain HTTP on a single machine, with no rate limiting and no account recovery. Do not reuse a password you use anywhere else. All learner data shown is anonymised and public.
